## 1. 显示页面（5 页）

五个页面可在后台启停和排序，USER 单击按配置顺序循环切换。

### 1.1 综合页 `overview`

- 大号时钟（HH:MM），NTP 同步、RTC 断电保持；
- 公历日期 + 农历日期；
- 当前天气（城市、天气现象、温度）；
- 室内温湿度（SHTC3，左上角状态栏）；
- 小智状态区：表情图标 + 状态/对话文本（支持小智 21 种表情）；
- 未完成待办摘要；
- Wi-Fi 信号、电池电量与充电状态图标。

### 1.2 日历页 `calendar`

- 当月月历网格（为控制 LVGL 对象数，用少量多行标签排版）；
- 每个日期标注农历日（初一显示月份）；
- 法定节假日标「休」、调休上班标「班」（数据源 holiday-cn，见 §5）；
- 二十四节气（本地算法）。

### 1.3 七日天气页 `forecast`

- 当前地点天气实况；
- 未来七日预报（天气图标、最高/最低温）；
- 头部显示上次刷新时间；手动刷新时显示「正在刷新…」。

### 1.4 AI 额度页 `quota`

- 每个已启用账号一张卡片，含供应商 Logo、账号名、额度信息；
- 信息分层（2026-08-12 重构）：
  - 大数字：5H（5 小时窗口）剩余 % 优先，无 5H 则显示周/长期额度；
  - 进度条：固定显示周/长期额度剩余 %；
  - 进度条下方：`周 N% · 绝对重置时间 · 倒计时`（如 `周 62% · 15日15时 · 3天2小时后`）；
  - DeepSeek 等只有余额的供应商走 fallback：隐藏进度条，显示余额；
- 一屏卡片数可配（1–4 张，默认 4）：1 张占满、2 张对半、3 张自适应、4 张 2×2；
- 超过一屏时生成子页，默认每 10 秒自动翻页（间隔 0–120 秒可配，0 = 关闭），也可在后台固定显示某一子页；
- 页面右上角显示上次额度刷新时间；账号刷新失败时卡片右上角显示红色警告标。

### 1.5 待办页 `todo`

- 常驻显示待办清单（内容、截止日期/时间、完成状态）；
- 数据来源 TodoManager（NVS `todos` 命名空间，≤32 条）；
- 后台编辑后立即刷新屏幕。

## 2. 按键操作

| 按键 | 场景 | 功能 |
|---|---|---|
| BOOT 单击 | 启动阶段（Starting） | 进入 Wi-Fi 配网 |
| BOOT 单击 | 综合页 | 开始 / 停止小智对话（先取消后台网络，避免与音频抢 SRAM） |
| BOOT 单击 | AI 额度页 | 立即刷新全部账号额度 |
| BOOT 单击 | 七日天气页 | 立即刷新天气（头部即时显示「正在刷新…」） |
| BOOT 单击 | 日历页 / 待办页 | 无操作 |
| USER 单击 | 任意 | 按后台配置顺序切下一页；AI 页多子页时先翻下一个子页 |
| USER 双击 | 任意 | 刷新全部数据（天气、传感器、时间） |
| USER 长按 | 任意 | 在综合页小智区域循环滚动系统信息（CPU、运行时间、SRAM/PSRAM、电池、Wi-Fi） |

- 任意按键操作都会退出省电状态；
- 连续 5 分钟无操作进入省电模式：UI 周期刷新从 1 秒降为 5 秒。

## 3. AI 额度监控

### 3.1 支持的数据源（provider）

| provider | 接口 | 凭据 |
|---|---|---|
| `codex` | `chatgpt.com/backend-api/wham/usage` | Bearer access token，可附 ChatGPT Account ID |
| `kimi` | `api.kimi.com/coding/v1/usages` | Bearer API key |
| `glm-cn` | `open.bigmodel.cn/api/monitor/usage/quota/limit` | Authorization API key |
| `glm-global` | `api.z.ai/api/monitor/usage/quota/limit` | Authorization API key |
| `deepseek` | `api.deepseek.com/user/balance` | Bearer API key |
| `generic-json` | 后台自定义 URL | 可选 Bearer，自定义总量/剩余字段名 |
| `manual` | 不联网 | 后台直接填写 5H / 周两个剩余百分比 |

### 3.2 刷新机制

- 默认每 5 分钟串行刷新（后台可配 1–60 分钟），开机约 5 秒后首次执行；
- 守卫：仅在设备空闲（Idle 且空闲 ≥30 秒）时执行，不抢语音链路；进入音频会话时后台网络立即取消；
- 单账号超时 10 秒、响应体 ≤16 KB；账号间有间隔防止上游限流；失败自动重试最多 3 次（指数退避 2s/4s/8s）；
- 失败时保留上次成功缓存并标记 `stale` + 错误信息，屏幕不因短暂断网清空；
- 后台可手动触发：全部刷新（`/api/refresh`）或单账号刷新（`/api/refresh-one`）。

### 3.3 每账号独立代理

- 每个非 manual 账号可独立启用 HTTP CONNECT 代理（`http://192.168.x.x:7890`），支持可选 Basic 认证；
- 代理只用于该账号的额度查询，不影响天气/节假日/语音/后台流量；
- 代理隧道内仍对目标 HTTPS 证书强校验（`MBEDTLS_SSL_VERIFY_REQUIRED`）；
- 代理 URL 经严格解析（`proxy_auth.h`，防 CRLF 注入）；后台提供代理诊断（`/api/proxy-diagnostic`，逐级检查 TCP → CONNECT → TLS）。

### 3.4 显示配置（后台「AI 页显示」）

| 配置项 | 范围 | 默认 |
|---|---|---|
| 每屏卡片数 | 1–4 | 4 |
| 自动翻页间隔 | 0–120 秒（0 = 不自动翻） | 10 |
| 固定页码 | 0 = 不固定，或 1–N（按账号数与每屏卡数动态计算） | 0 |

## 4. 天气

- **实时天气**：高德 Web 服务（`/v3/weather/weatherInfo`），需在后台保存高德 Key（只写不回显）和城市 adcode（后台按省份/城市选择，自动带出经纬度与 adcode）；
- **七日预报**：Open-Meteo（按城市经纬度，**无需 Key**）；
- **降级**：Open-Meteo 失败时自动降级为高德三日预报；
- **刷新**：默认 15 分钟（后台可配 5–120 分钟），仅在联网且空闲时执行；
- **容错**：任何失败都保留最后有效快照；
- **手动刷新入口**：七日天气页 BOOT 单击、USER 双击、后台「刷新天气」按钮（`/api/weather/refresh`）；
- **诊断**：`/api/weather-diagnostic` 返回最近一次请求的接口、HTTP 状态与结果。

## 5. 日历、节假日与农历

- 年度节假日数据源默认 `https://raw.githubusercontent.com/NateScarlet/holiday-cn/master/{year}.json`（后台可改源），同步后缓存到 NVS，失败保留旧缓存；
- 日历页用「休」标放假、「班」标调休上班，其余日期显示农历；
- 农历转换在设备本地完成（板载算法，有效范围 1900–2049），不依赖网络；
- 二十四节气用本地近似公式；
- 后台可「立即同步」本年度节假日（`/api/calendar/sync`）。

## 6. 待办与语音备忘

### 6.1 待办（TodoManager）

- 字段：`id`、`content`、`due_date`、`due_time`、`completed`、`order`、`created_at`、`updated_at`（≤32 条）；
- 写入用原子提交（拷贝→校验→持久化→提交），日期严格校验 ISO 格式；
- 维护方式：后台页面、REST API（Bearer Token）、综合页/待办页显示；
- 首次启动自动把旧 `memo` 命名空间数据迁移到 `todos`。

### 6.2 待办 REST API（自动化）

后台「待办 API」区域生成/重置 Bearer Token（24 字节 hex）：

```bash
DEVICE=http://<设备IP>:8080
TOKEN='后台复制的 TOKEN'

curl -H "Authorization: Bearer $TOKEN" "$DEVICE/api/todos"                      # 列表
curl -X POST -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
     -d '{"content":"提交周报","due_date":"2026-08-13","due_time":"18:00"}' \
     "$DEVICE/api/todos"                                                        # 新增
curl -X PUT -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
     -d '{"completed":true}' "$DEVICE/api/todos/<id>"                           # 完成
curl -X DELETE -H "Authorization: Bearer $TOKEN" "$DEVICE/api/todos/<id>"       # 删除
```

Bearer 路径不需要 Cookie/CSRF，适合 Home Assistant、iOS 快捷指令、局域网脚本。

### 6.3 语音备忘与到点提醒

- 语音说「提醒我下午 3 点开会」「记住买牛奶」→ AI 调用 `self.memo.add`；
- 带 `HH:MM` 时间标签的备忘到点后自动弹窗提醒并删除；
- 语音工具：`self.memo.add` / `list` / `done` / `clear`。

## 8. 局域网后台（Admin Server）

地址：`http://<设备IP>:8080/admin`（单页应用，完全内嵌、无 CDN 依赖，离线可用）。

### 8.1 认证

- 首次访问设置密码（8–72 位），用户名固定 `admin`；
- 登录返回 `sid` Cookie（`HttpOnly; SameSite=Strict`，闲置 30 分钟失效，重启后从 NVS 恢复会话）；
- 所有写请求必须携带会话 Cookie + `X-CSRF-Token`；
- 待办接口额外支持 Bearer Token（见 §6.2）；
- 密码存随机盐 + SHA-256 摘要，不存明文。

### 8.2 后台功能区块

- **仪表盘**：运行状态、上次全部刷新成功时间、设备信息（heap/PSRAM/信号/IP/固件/分区/电池/温湿度/SD 卡）；
- **AI 账号**：增删改、启停、排序、代理设置、单账号刷新、实时预览、AI 页显示配置；
- **页面**：五页启停与排序、立即切页、屏幕截图（`/api/display/screenshot`）；
- **天气**：省份/城市选择、高德 Key、刷新间隔、上次刷新时间、立即刷新、诊断；
- **日历**：节假日源配置、立即同步；
- **待办**：增删改查、完成切换、API Token 生成/重置；
- **Wi-Fi**：查看当前连接、已保存列表、新增、切换、删除、设默认、断开、临时 AP 热点；
- **设备**：音量调节。

## 9. 传感器、时钟与电源

- **SHTC3 温湿度**：I2C，温度变化 >0.2 °C 或湿度 >1% 才更新显示；
- **PCF85063 RTC**：纽扣电池备份，断电保持时间；首次联网 NTP 同步后写入 RTC，每 24 小时自动校准；检测到系统时间异常时从 RTC 恢复；
- **电池**：ADC（GPIO4，3:1 分压），10 次采样平均 + EMA 滤波 + 抛物线拟合（4200 mV→100%，3700 mV→50%，3300 mV→0%）；
- **省电**：5 分钟无操作 UI 刷新降频（1s→5s）；音频会话优先（后台网络立即取消）。

## 10. 持久化与分区

自定义分区表 `partitions/v2/16m_rlcd_quota.csv`（16 MB）：

| 分区 | 大小 | 用途 |
|---|---:|---|
| `nvs` | 16 KB | Wi-Fi、天气/日历/待办配置、旧 memo |
| `ota_0` / `ota_1` | 各 ~5 MB | 双 OTA 应用槽 |
| `assets` | ~5.75 MB | 字体、表情、图标 |
| `quota_nvs` | 256 KB | 管理员密码、API Token、额度配置与缓存 |

NVS 命名空间：`weather`（高德 Key/城市）、`calendar`（节假日缓存）、`todos`、`memo`（旧）、`quota_nvs/admin`（密码摘要、Token）、`quota_nvs/quota`（账号、页面配置、缓存）。

> 只写应用分区不清除配置；全片擦除或更换分区表会丢失全部配置。**更换分区表必须完整烧录，不能 OTA。**

## 11. 安全设计

- 密钥只写不回显：所有 GET 接口只返回 `has_secret` / `has_proxy_auth` 布尔；编辑时留空 = 保留旧值，显式 clear 才删除；
- 后台写操作必须 Cookie + CSRF；待办自动化走独立 Bearer Token；
- 所有外部 HTTPS 经 CA bundle 强校验（`MBEDTLS_SSL_VERIFY_REQUIRED`），代理隧道内同样校验目标证书；
- 代理 URL 严格解析，防 CRLF 注入；
- 后台联网串行化 + 可取消（`BackgroundNetworkSession`），不与语音链路抢资源；
- 配置写入原子提交（`CommitValidatedUpdate`），失败回滚；
- 后台为**明文 HTTP，仅限可信局域网使用，禁止公网端口映射**；密码 KDF 为单轮 SHA-256（较弱，加固在路线图上）。

## 12. 已知限制与遗留

- **应用分区余量约 6%**：新增字体/资源/代码前必须检查 `check_sizes.py` 输出；
- **内部 SRAM 紧张**：UI 严格限制 LVGL 对象数（曾因对象过多跌到 387 字节崩溃），改动后需验证 minimal SRAM ≥ 20 KB；
- **死代码仍在编译**：`music_ui.cc`、`pomodoro_ui.cc`、`pomodoro_manager`、上游音乐播放框架等不可达代码仍占 Flash（清理计划见 `PROJECT_CLEANUP_PLAN.md`）；
- **第三方接口易变**：Codex 使用 ChatGPT 非公开后端，各 provider 解析器无回归 fixture；
- **农历算法范围**：1900–2049；
- **深度睡眠未实现**：当前最省电的是 UI 降频，不是真正休眠。
